# Maintained native scalar adapter, local private review

Tracking private #56. This local software change extends the existing
`runoff_routing.regression_dataset` runner from `dd69068`; it is not another runner
or solver. Publication is private as a reviewable patch; no public transfer or
production-engine acceptance is implied.

`--custody-root` supplies an explicitly selected external dataset for supplemental
native reports, authenticated typed events and source bindings. The register keeps
relative contained paths, sizes and SHA-256 identities. Frozen policy and reporting
evidence locators are verified during preflight. Native reports are parsed using the
existing inspector, preserving original tokens and complete horizons.

`--series` supplies actual candidate stored-Q and timestep hexadecimal values, with
candidate revision, source module hashes and optional wheel identity. These must
match the dataset's qualified candidate, typed inputs and ordinate CSV. The frozen
scalar comparator is copied byte-for-byte; #59 controls use package imports only.
Peak/time are attempted first; volume eligibility is independent. Each field retains
its own verdict, original selector/token and exact actual representation. Missing
material, genuine truncation and unsupported profiles remain explicit. Zero-flow time
remains incomplete and makes the complete requested scalar aggregate non-success.

Pyright pass. Separate private dataset records report actual native-backed cached
