## Scope implemented on topic branch

- `engine_execution.execute_loaded_engine` reuses exactly the existing
  selected-engine dispatch, including explicit python-cmd and optional native CMD;
  `run_engine_project` delegates through the same in-memory dispatcher.
- `project_batch.py` implements a strict versioned request **separate** from the
  existing schema-2 JSON project; immutable typed effective event RunModels are
  constructed without writing a temporary project, changing input evidence,
  reordering catchment controls or changing established numerical kernels.
- Both streaming `iter_project_events` and collected `run_project_events`
  retain event order, duplicates and typed failed/unsupported results without
  stopping adjacent events.
- CLI produces complete full-horizon JSON/CSV (one row per computed sample,
  one row per failure) and concise text summary, all exclusive-create.
  Outcome identity retains source and effective model hashes, engine/profile,
  site IDs, units, per-event horizon and error diagnostics. The derived physical
  trapezoidal volume is separate from unavailable native-inclusive volume.
- Three public standalone example/event requests and documentation, without
  private runtime files, generated storms, Monte Carlo, TOML or GUI.
