## Working rules

1. A software PR may integrate after exact-head source/wheel checks, independent Codex review and required owner approval **without waiting for unrelated scientific issues to close**, provided it does not claim unsupported native or full engineering accuracy.
2. A native-compatible algorithm may be implemented only for source-authenticated rules admitted under #150; unknown rules are explicit unsupported, not guessed, relabelled or silently mapped to project defaults. Preserve the `monte-carlo-statistics/1` method, stable RNG/plan IDs, engine/default behavior, and published fixtures.
3. The scientific research record may stay open after a bounded parser/adapter/sampler/frequency implementation is complete. Conversely a parser or synthetic check does not count as physical/native acceptance.
4. Original native/manual/private evidence stays in approved custody. There is no new RORBwin MC run, decompilation, native batch, publication, distribution activation or statistical tail extrapolation authorised by this issue taxonomy.
5. New software branches target **current `main`** rather than merged #151. Data/reader work uses the existing canonical ryan-tools dependency; no duplicate parser or parallel runner.
