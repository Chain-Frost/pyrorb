# ARR2019 Book 2 versus ARR Data Hub 2026v1 — ARF method review (#193)

**Decision (17 November 2026): no ARF formula or coefficient change.** Keep the existing `ARR2019_BOOK2_V4_1_2_4_1_TO_2_4_4` computational policy. The latest official ARR guideline located is **ARR 2019, Version 4.2** (2024 climate update), not a separate ARR2026 Book 2. The **Data Hub 2026v1** is a change to the source service, IFD products and jurisdiction-sensitive selection, **not evidence of replacement ARF equations**. This is a bounded method/source review, not certification of a 2026 design workflow.

## Authoritative references and versions

1. [ARR Book 2, Version 4.1, Chapter 4, equations 2.4.1–2.4.4 and Table 2.4.2](https://www.arr-software.org/pdfs/ARR_190514_Book2_V4.1.pdf) — the originally pinned numerical implementation.
2. [ARR Book 2, Version 4.2, Chapter 4, equations 2.4.1–2.4.4 and Table 2.4.2](https://www.arr-software.org/pdfs/ARR_190514_Book2_V4.2.pdf) — reviewed against 4.1. Version 4.2's front-matter change log principally updates **Book 1 Chapter 6**; Book 2's listed minor changes are in **Chapters 1 and 3**, not Chapter 4.
3. [ARR guideline version index](https://www.arr-software.org/arrdocs) and [Geoscience Australia ARR guidance](https://arr.ga.gov.au/arr-guideline) — official reference/version availability.
4. [ARR Data Hub changelog](https://data.arr-software.org/changelog), **2026v1, 21 August 2026** — Default IFD products/current/historical/native baselines, optional catchment outlet, three-significant-figure IFDs, climate layers and preburst source changes.
5. [ARR Data Hub API/about](https://data.arr-software.org/about) — separately supplied outlet chooses jurisdiction rules for Default IFD, storm losses, preburst and **ARF parameters**; the API is a source service, not a new Book 2 equation.

The primary ARR Book 2 v4.1/v4.2 Chapter 4 coefficients are identical in their printed tables, including South-West Western Australia `e = 3.85E-06` and Inland Arid `g = +0.129`. The distinct `3.845E-06` value in third-party scripts is **not** a new 2026 parameter. The new test locks all ten published v4.2 nine-value region rows independently of the production dictionary.

## Verified code boundaries and tests

- `src/runoff_routing/arr_arf.py` retains `Decimal` inputs/outputs and published-vs-legacy coefficient provenance. Its built-in published source remains **Book 2 v4.1** in the immutable policy identifier for backward-compatible audit records; **v4.2 Chapter 4's unchanged equations do not justify silently renaming historic policy IDs**.
- `src/runoff_routing/arr_import.py` accepts versioned `2026v1` `RecIFD` default baseline tables; `QueryLocation` stores optional outlet, and absent/unknown `ARFParams` and other layers remain explicitly unprocessed.
- `src/runoff_routing/arr_storm.py` manually selects a 2026v1 IFD table/cell; no ARF, climate, loss or preburst calculation is applied. `apply_arr2019_arf_to_bom_storm` rejects a 2026 Data Hub storm instead of silently treating that source as an old BoM gross rainfall file.
- `tests/test_arr_arf_2026.py` adds an authored-synthetic v4.2 table snapshot, method-branch/profile guards, explicit 2026 current/historical/native baseline tests, source SHA/outlet/layer preservation, and a negative ARR2026-to-BoM-ARF-adapter test. The existing independent float equation and official 0.929 worked-example tests are retained unchanged.

**Limitations:** No live production 2026v1 `ARFParams` numeric layer was parsed or used to demonstrate provider equivalence; 2026v1 SSP-adjusted source curves and jurisdiction-specific selected default IFDs are not automatically valid RORB design events. The synthetic fixture does not demonstrate actual provider regional boundaries, location-specific IFD selection, or compliance. No RORBwin native, climate, loss, preburst, spatial-hydrology or GUI claim follows from this review.
